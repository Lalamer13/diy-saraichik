# DIY Сарайчик — MVP 0.1

Первая работающая версия личной коллекции DIY-идей. Интерфейс адаптирован под телефон.

## Что уже работает
- Добавление идеи с названием, ссылкой, заметкой, категорией и приоритетом.
- Карточки, поиск и фильтрация по статусу.
- Редактирование, теги, смена статуса и удаление.
- Экспорт и импорт JSON.
- PWA-манифест и service worker для установки/кэширования.
- Подготовлена поддержка Android Share Target: можно отправлять ссылку из меню «Поделиться» в установленное приложение после публикации по HTTPS.

## Важно
Это локальный прототип: данные хранятся в `localStorage` браузера на одном устройстве. Очистка данных браузера может удалить коллекцию. Регулярно скачивай JSON-копию. Пока не подключены облачная синхронизация и ИИ — они следующие этапы.

## Самый простой запуск на компьютере
1. Распакуй архив.
2. Открой терминал в папке `diy_saraichik_mvp`.
3. Запусти локальный сервер:

   **Windows**
   ```powershell
   py -m http.server 8000
   ```

   Если `py` не работает:
   ```powershell
   python -m http.server 8000
   ```

4. Открой `http://localhost:8000` в браузере.

Для проверки обычного интерфейса можно открыть `index.html` напрямую, но PWA, офлайн-кэш и установка требуют `localhost` или HTTPS.

## Как открыть на Android
Чтобы телефон видел сайт по локальной сети, компьютер и телефон должны быть в одной Wi-Fi-сети. Запусти сервер на компьютере и открой в браузере телефона адрес вида `http://IP-АДРЕС-КОМПЬЮТЕРА:8000`. На Windows может понадобиться разрешить Python в брандмауэре. Для установки PWA и Android Share Target обычно нужен опубликованный сайт по HTTPS; `localhost` на самом телефоне не указывает на компьютер.

## Что сделать перед публичной публикацией
- Разместить статические файлы на HTTPS-хостинге.
- Проверить `manifest.json` и Android Share Target на реальном телефоне.
- Для облачного хранилища подключить авторизацию и базу данных, настроить правила доступа (RLS).
- ИИ подключать через серверную функцию. Никогда не помещать секретный API-ключ в `app.js` или другие файлы, отправляемые браузеру.
